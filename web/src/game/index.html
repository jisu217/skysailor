무게추를 움직여 돔의 자세를 잡아보세요.
직접 조종하거나 자동 전략의 비행을 계산해 다시보세요.

자동 전략 · 계산 후 다시보기 C 회전 레일 전용 · 높이 3m / 초기 5° / 최대 10초. 아래 바람·질량·레일 설정을 사용합니다. 0.1초마다 0.3초 앞을 예측하며 미래 바람은 알지 못합니다.
결과는 서버에 저장되며 다시 재생할 수 있습니다.
비행 다시보기
비행하면 자동으로 기록됩니다.
380mm는 새 CFD가 아닌 기존 계수 환산입니다. 돔 25g은 임시값입니다. 크기 선택은 C 레일 모델에 적용됩니다.
패드는 돔 기준 X/Y 이동속도, 슬라이더는 Z 이동속도입니다. 중앙 정지 버튼은 모두 0으로 만듭니다. 길이·이동 범위 상한 없음. 각 막대 지령속도와 ±0.5N 힘 제한을 적용합니다. 돔은 380 × 80mm / 25g입니다.
레일 설정 · 임시값 / 새 낙하 시 적용 직선 속도는 레일에 대한 추의 상대속도입니다. 회전은 관성과 토크 한도로 가감속하며, 외력에 의한 회전 속도 초과는 가능합니다. 직선 구동은 힘·가속도 제한이 없는 이상적 장치입니다. 레일·축·가이드의 공기저항과 마찰은 제외합니다.
중앙에서 세 줄이 같은 길이인 기준입니다. 최소 120mm에서는 목표가 고정점 평면에 놓입니다. 줄만으로 실제 추를 그 평면에 가둘 수는 없습니다. 설정 후 ‘새 낙하’를 눌러 적용하세요. 최근 2초의 물리 상태를 보관합니다.
연결 중…

패드는 카메라에서 보이는 기체 방향과 기울기에 맞춰 표시됩니다. 클릭하거나 드래그하세요. A/B의 꼭짓점은 줄 고정점이며 C의 원은 가이드, 주황 선은 회전 레일입니다. 노랑은 방향·속도 입력, 민트는 구동 목표, 분홍은 실제 추입니다. 중앙은 정지, 바깥쪽은 최대 지령속도이며 입력은 클릭 후 유지됩니다. 실제 속도는 각 모델의 구동 한도에 따라 달라집니다.
A는 줄의 탄성과 모터 힘 제한을 적용합니다. B는 추를 평면에 구속하고 가장 빠른 줄이 속도 상한을 넘지 않게 이동합니다. C는 가까운 회전 방향을 선택하고, 추가 중심을 통과해 레일 양쪽으로 이동합니다.

비행 로그는 서버에 자동 저장됩니다. 현재 로그 다운로드

저장된 비행 로그 (최근 100개)

← / A: 설정 간격 되돌리기 · → / D: 설정 간격 진행
Space: 재생 / 일시정지 · R: 새 낙하
새 낙하 시 화면의 다시보기는 초기화되지만, 저장된 로그 파일은 유지됩니다.

패드 입력은 화면 방향에서 돔의 X/Y 좌표로 변환됩니다. 카메라는 뒤쪽에서 수평을 유지하며 따라갑니다. 마우스 드래그로 시점 회전, 휠로 확대.
3m / 초기 5°. A/B는 반지름 120mm, C는 선택한 돔의 반지름 범위에서 이동합니다. 느슨한 줄은 밀 수 없습니다.

왜 바로 뒤집힐까?

정지 상태로 놓아도 횡풍과의 상대속도는 이미 큽니다. 공기 토크가 먼저 생기고 줄·무게추는 늦게 반응할 수 있습니다. 먼저 무풍에서 작은 조작으로 반응 방향과 지연을 익혀보세요. 강풍에서는 조작만으로 회복하지 못할 수도 있습니다.

예비 CFD와 회전 감쇠 근사입니다. 실제 기체의 안정성을 검증한 게임은 아닙니다.
