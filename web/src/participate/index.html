1. 예제를 받아 코드 작성

예제 Agent ZIP을 풀고 agent.py를 수정하세요. PID·MPC·신경망 등 알고리즘은 자유입니다.

class Agent:
    def reset(self):
        # 매 비행 시작: 기억 초기화·모델 로딩
        self.steps = 0

    def act(self, observation):
        self.steps += 1
        return [0.0, 0.0]  # 중립 지령 예제

입력: 17개 관측값. 출력: [레일 회전 속도 지령, 추 직선 속도 지령], 각각 −1~1. 0은 속도 지령 0이며 추를 중앙으로 옮기라는 뜻은 아닙니다.

시뮬레이션 0.02초마다 호출됩니다. 학습은 제출 전에 하고, 필요한 가중치를 함께 넣으세요.

관측값 17개 보기
0:3   세계 위쪽 단위벡터 (기체 좌표계)
3:6   각속도 / 10 (기체 좌표계)
6:9   상대 공기속도 / 10 (기체 좌표계)
9     허브 높이 / 3
10,11 레일 각도의 sin, cos
12    추 위치 / 돔 반지름

14    추 직선 속도 / 최대 직선 속도
15:17 이전 행동

2. 코드와 가중치를 ZIP으로

ZIP을 열면 agent.py가 바로 보여야 합니다. 바깥 폴더를 포함하지 마세요.

agent.zip
├── agent.py
├── model.pt           # 필요할 때만
├── helpers.py         # 필요할 때만
└── requirements.txt   # 선택

파일이 있는 폴더에서:

python3 -m zipfile -c agent.zip agent.py model.pt

가중치가 없으면 model.pt를 명령에서 빼세요. 파일은 agent.py 기준 상대 경로나 /agent에서 읽을 수 있습니다.

공통 환경: Python 3.12 · NumPy 2.5.3 · PyTorch 2.8.0 CPU. 추가 패키지는 설치하지 않습니다. 모델은 CPU로 불러오세요.

3. 지표를 선택하고 제출

  1. Tailscale 초대 수락 후 앱을 연결합니다.
  2. 대시보드 상단에서 무풍 / 실측 바람 지표를 고릅니다.
  3. + Agent 제출 → Python Agent · ZIP을 선택합니다.
  4. ZIP 파일과 참가자·Agent 이름을 입력하고 제출합니다.

기체 크기·질량 등은 지표의 평가 조건·기체 기본값 보기에서 확인하세요. 추 질량(0.1–100g)과 중심 아래 레일 축 길이(5–300mm)는 제출마다 지정합니다. 기체 설정과 제어 성능을 함께 비교하며, 모든 제출은 같은 5개 공개 바람·초기 자세 조건으로 평가합니다.

4. 순위와 3D 비행 확인

평가가 완료되면 순위표에 자동 반영됩니다. 제출을 클릭하면 오른쪽에서 비행을 볼 수 있습니다. 비행 1~5를 골라 비교하세요.

점수: 5회 평균 고도 적분(m·s). 높이를 오래 유지할수록 높습니다. 시작 3m, 착지 또는 시뮬레이션 10초에 종료됩니다.

실패했다면: 평가 상태의 오류를 확인하세요. ZIP 구조, 행동 범위, 라이브러리, 시간 제한을 점검하면 됩니다.

실행 제한 보기
  • 초기화 20초 / 행동 1회 0.25초 / 비행당 실제 실행 시간 60초
  • CPU 1개 / 메모리 1GB / 네트워크·GPU 없음
  • ZIP 20MB / 압축 해제 100MB / 최대 256개 항목
  • 행동은 유한한 수 2개, 각각 −1~1. NaN·무한대 불가
  • requirements.txt는 numpy·torch 또는 위의 고정 버전만 허용
