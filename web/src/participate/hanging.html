03 · 3점 매달린 추 / 실측 바람

대시보드 · 전용 예제 ZIP · 구조 모형

링의 120° 간격 세 액추에이터가 한 점에 연결되고, 그 아래 추는 볼 관절로 자유롭게 흔들립니다. 기존 레일 Agent와 입출력 규격이 다릅니다. reset()은 인자 없이 호출합니다.

class Agent:
    def reset(self): pass
    def act(self, observation):
        return [0.0, 0.0, 0.0]

행동 3개: 각 액추에이터의 목표 길이 변화 속도 / 설정한 최대 속도. 범위 −1~1. 양수는 늘림, 음수는 줄임, 0은 목표 길이 유지. 0.02초마다 호출합니다. 실제 속도는 부하와 서보 응답에 따라 달라지며 엄격한 실제 속도 제한은 아닙니다.

관측 인덱스정의 (0부터)
0–2돔 좌표계에서 세계 위쪽 단위벡터
3–5돔 좌표계 각속도 / 10 rad/s
6–8돔 좌표계 상대 바람 속도 / 10 m/s
9돔 중심 고도 / 3m
10–12돔 기준 연결점 XYZ / 0.2m
13–15연결점의 돔 기준 이동 속도 / 0.1m/s
16–18돔 좌표계 연결점→추 단위벡터
19–21볼 관절의 국소 상대 각속도 / 10rad/s
22–24세 액추에이터 실제 길이 / 0.3m
25–27직전 행동

액추에이터 순서는 돔 XY 평면에서 +X, 120°, 240°입니다. Z는 돔 위쪽입니다. 로컬 환경: hanging.HangingEnv(hardware). hardware는 payload_mass_g, ring_radius_mm, connector_drop_mm, pendulum_length_mm, actuator_speed_mm_s 딕셔너리입니다.

추 0.1–100g, 링 반지름40–150mm, 초기 연결점 아래거리40–150mm, 매달린 길이15–120mm, 목표 신축 속도5–100mm/s를 제출 창에서 설정합니다. 학습에도 같은 값을 사용하세요. ZIP 규격과 실행 제한은 기본 안내와 같습니다.

고정 조건: 돔380×80mm/25g, 링·구동부 질량3g(링에 집중), 연결점1g, 각 액추에이터0.5N, 초기 길이±30mm 스트로크. 연결점은 XY ±링 반지름×0.6, Z 초기점±40mm 및 링 아래 최소20mm 범위의 소프트 스톱으로 제한합니다. 서보는 길이 오차80N/m, 감쇠1.2N·s/m. 추 관절 감쇠0.00001N·m·s/rad, 추는 반지름10mm 구의 관성입니다. 현수 링크는 질량 없는 강체 연결로 모델링합니다.

점수: 공개 seed0–4 전체 질량중심 고도 적분 평균. 자유 낙하에서는 추를 항상 수직으로 강제하지 않습니다. 내부 반작용과 진자 운동은 MuJoCo로 계산합니다. 돔 공기력은 잠정 CFD 환산, 현수부 공기저항·자체 충돌은 제외합니다. 실제 제작 성능 검증 전의 개념 비교용입니다.
