# Star catalog attribution

Source: HYG Database v4.1, David Nash / Astronomy Nexus.
https://github.com/astronexus/HYG-Database
https://github.com/astronexus/HYG-Database/blob/main/hyg/CURRENT/hygdata_v41.csv

Changes: retained 8,920 entries with apparent visual magnitude <= 6.5, excluding the Sun; retained only right ascension (hours), declination (degrees), and apparent magnitude; rounded coordinates to six decimal places. Coordinates are J2000, not a simulation of the current observing time. Display brightness is compressed for visibility, and all stars use a uniform cool-white display color.
