Tailscale 초대를 수락하고 앱을 연결하세요.
http://100.120.214.39:8080/arena/ → + Agent 제출 → 예제 Agent ZIP 다운로드.
처음에는 예제를 그대로 제출해 전체 흐름부터 확인해도 됩니다.

2. agent.py 수정하기
ZIP 최상위 agent.py에 Agent 클래스를 만듭니다.
reset(): 비행 시작 때 호출됩니다. 내부 기억 초기화, 모델 로딩을 하세요.
act(observation): 관측값을 받아 행동 두 개를 반환합니다.
[회전 속도 지령, 추 직선 속도 지령], 각각 -1~1.
0은 속도 지령 0이며, 무게추를 중앙으로 이동시키라는 뜻은 아닙니다.
최대 지령은 회전 180도/s, 직선 30mm/s. 관성과 구동 한계가 적용됩니다.
act는 시뮬레이션 시간 0.02초마다 호출됩니다.
PID, MPC, 신경망 등 알고리즘은 자유입니다. 학습은 제출 전에 하세요.

최소 예제 (학습된 제어기가 아닌 중립 지령):
class Agent:
    def reset(self):
        self.steps = 0

    def act(self, observation):
        self.steps += 1
        return [0.0, 0.0]

관측값 observation은 float32 17개입니다.
[0:3] 기체 좌표계에서 본 세계 위쪽 단위벡터
[3:6] 기체 좌표계 각속도 / 10
[6:9] 기체 좌표계 상대 공기속도 / 10
[9] 허브 높이 / 3
[10], [11] 레일 각도의 sin, cos
[12] 추의 레일상 위치 / 돔 반지름
[13] 레일 각속도 / 최대 각속도
[14] 추 직선 속도 / 최대 직선 속도
[15:17] 이전 행동 두 개

3. ZIP 만들기
agent.py와 필요한 모델·보조 코드 파일을 함께 압축하세요.
ZIP을 열면 agent.py가 바로 보여야 합니다. 바깥 폴더를 포함하지 마세요.
예: agent.zip → agent.py, model.pt, helpers.py, requirements.txt(선택).
파일이 있는 폴더에서: python3 -m zipfile -c agent.zip agent.py model.pt
모델 파일이 없으면 model.pt를 명령에서 빼세요.
가중치는 agent.py 기준 상대 경로나 /agent에서 읽을 수 있습니다.

4. 제출하고 비행 보기
대시보드 상단에서 지표(무풍 / 실측 바람)를 선택합니다.
+ Agent 제출 → Python Agent · ZIP → 파일 선택 → 참가자·Agent 이름 → 제출.
서버가 동일한 5개 공개 조건에서 평가합니다.
완료되면 순위표에 표시됩니다. 제출을 클릭하면 오른쪽에 3D 비행이 나옵니다.
비행 1~5를 골라 재생할 수 있습니다. 실패 원인은 평가 상태에 표시됩니다.
점수는 5회 평균 고도 적분(m·s)이며 높을수록 좋습니다.
시작 높이는 3m, 비행은 착지 또는 시뮬레이션 10초에 종료됩니다.
기체 크기·질량·구동 한계는 지표의 ‘고정 평가 조건 보기’에서 확인하세요.

실행 환경과 제한
Python 3.12 / NumPy 2.5.3 / PyTorch 2.8.0 CPU, 표준 라이브러리.
추가 패키지는 자동 설치되지 않습니다. requirements.txt는 위 두 패키지만 허용.
네트워크·GPU 사용 불가. 모델은 CPU로 불러오세요.
초기화 20초 / act 1회 0.25초 / 비행당 실제 실행 시간 60초.
CPU 1개 / 메모리 1GB / ZIP 20MB / 압축 해제 100MB / 최대 256개 항목.
NaN, 무한대, 범위 밖 행동, 시간 초과는 평가 실패입니다.
자세한 규격은 PYTHON_AGENT.txt를 참고하세요.

주의: participant/evaluate.py는 이전 로컬 Agent.reset(seed) 규격입니다.
위 웹 제출용 reset() 예제와 직접 혼용하지 마세요. 첫 확인은 웹 제출로 하세요.
380mm 공기력은 기존 CFD 계수 환산값이며 실제 기체 검증을 대체하지 않습니다.

제출별 기체 설정: 추 질량 0.1–100g(기본 18g), 중심 아래 레일 축 길이 5–300mm(기본 5mm)를 제출 창에서 지정합니다. 축 길이는 돔 중심에서 레일 평면까지의 아래 방향 거리입니다. 같은 지표에서 기체 설계와 제어 성능을 함께 비교하며 설정은 순위표와 리플레이에 저장됩니다.
